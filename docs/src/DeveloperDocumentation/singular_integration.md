# Singular Integration

This section explains how OSCAR interacts with Singular.

## The Julia package [Singular.jl](https://github.com/oscar-system/Singular.jl)

This package provides an interface between Singular and Julia.
Its [documentation](https://oscar-system.github.io/Singular.jl/stable/)
describes the Singular rings, ideals, modules and matrices it wraps,
and how Singular libraries are made available as Julia functions.
Inside OSCAR, the package is available as `Oscar.Singular`.

## Using Singular from OSCAR

Ideals in OSCAR polynomial rings are backed by Singular ideals,
and `Oscar.singular_generators` returns the Singular ideal generated by
the generators of an OSCAR ideal.
Singular kernel functions such as `std` are available as Julia functions
in `Oscar.Singular`, and the functions of a Singular library `foo.lib`
are available in `Oscar.Singular.LibFoo`;
there is no need to load the library first.
The results are Singular objects, `ideal(R, x)` turns a Singular ideal
`x` back into an OSCAR ideal in the ring `R`.
```jldoctest
julia> R, (x, y) = polynomial_ring(QQ, [:x, :y]);

julia> I = ideal(R, [x^2 + y^2 - 1, x - y]);

julia> SI = Oscar.singular_generators(I)
Singular ideal over Singular polynomial ring (QQ),(x,y),(dp(2),C) with generators (x^2 + y^2 - 1, x - y)

julia> Oscar.Singular.std(SI)
Singular ideal over Singular polynomial ring (QQ),(x,y),(dp(2),C) with generators (x - y, 2*y^2 - 1)

julia> ideal(R, Oscar.Singular.LibPrimdec.minAssGTZ(SI)[1])
Ideal generated by
  2*y^2 - 1
  x - y
```
Note that these functions are not part of OSCAR's official interface
and may change.
Prefer the OSCAR functions whenever they exist
(`groebner_basis(I)` and `minimal_primes(I)` in the example above),
and please
[open an issue](https://github.com/oscar-system/Oscar.jl/issues)
if you need a Singular function that OSCAR does not provide.
