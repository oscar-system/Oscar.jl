# Primary decomposition

This is a native implementation of the algorithms of Singular's `primdec.lib`
for ideals in polynomial rings over `QQ` or a finite field: the algorithms of
Gianni–Trager–Zacharias and of Shimoyama–Yokoyama, as well as minimal
associated primes.
