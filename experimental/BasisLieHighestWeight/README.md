# Bases for highest weight modules

## Aims

This package provides code for computing monomial bases of highest weight modules for semisimple complex Lie algebras,
using a divide-and-conquer approach.
It started as the accompanying code for the OSCAR book chapter "Monomial Bases in Lie Theory" by Fang and Fourier,
but has since been extended to cover monomial bases of:
- Highest weight modules for semisimple complex Lie algebras
- Demazure modules for semisimple complex Lie algebras
- the degree-truncated coordinate ring of the Kodaira embedding of the generalized flag variety into the projective space of a highest weight module
- the degree-truncated coordinate ring of the Kodaira embedding of a Schubert variety into the projective space of a Demazure module


## Status

It is still under active development, and the API is not yet stable.
We are working on improving the performance of the code, and on adding more features.
