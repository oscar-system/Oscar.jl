# Complex reflection groups

This chapter fixes the mathematical conventions used by the implementation before
describing types, reference markings, and concrete matrix realizations. The standard
reference is [LT09](@cite).

## Theoretical conventions

### Reflections and Hermitian forms

Let $V$ be a finite-dimensional complex vector space. The **fixed space** of
$g\in\mathrm{GL}(V)$ is

```math
\operatorname{Fix}(g)=\ker(1-g).
```

An element $g\in\mathrm{GL}(V)$ is a (complex) **reflection** if it has finite order and
its fixed space is a hyperplane. A **complex reflection group** is a finite subgroup of
$\mathrm{GL}(V)$ generated by reflections.

A Hermitian inner product $(\mathord\cdot,\mathord\cdot)$ is taken to be linear in the
first argument and conjugate-linear in the second. A transformation $g$ is **unitary with
respect to this form** if

```math
(gv,gw)=(v,w)
```

for all $v,w\in V$. Thus, unitarity is relative to a chosen Hermitian form. Averaging any
positive-definite Hermitian form over a finite group gives an invariant one, so every finite
complex matrix group is unitarizable. It need not preserve the standard form in the current
basis.

Let $s$ be a reflection and choose an $s$-invariant Hermitian form. Then

```math
V=\ker(1-s)\mathbin{\perp}\operatorname{im}(1-s).
```

The image is a line. A nonzero vector $\alpha\in\operatorname{im}(1-s)$ is a **root** of
$s$, determined up to a nonzero scalar. If $s\alpha=\zeta\alpha$, there is a unique linear
form $\alpha^\vee\in V^*$ such that

```math
s(v)=v-\alpha^\vee(v)\alpha,
\qquad
\alpha^\vee(\alpha)=1-\zeta.
```

It is the **coroot** relative to the chosen root. For the chosen invariant Hermitian form,

```math
\alpha^\vee=(1-\zeta)\frac{(\mathord\cdot,\alpha)}{(\alpha,\alpha)}.
```

!!! warning
    In OSCAR, matrices act from the right on row vectors. Thus a matrix $A$ fixes the
    vectors $x$ satisfying $xA=x$. Formulas transferred from sources using left actions
    usually require transposing the matrices.

### Type, support, and rank

The **type** of an irreducible complex reflection group
$G\subseteq\mathrm{GL}_n(\mathbb C)$ is its conjugacy class in
$\mathrm{GL}_n(\mathbb C)$. Thus changing basis does not change the type. Conjugation
induces an isomorphism between the image groups, but no separately chosen abstract-group
identification is part of the definition. For unitary irreducible reflection groups,
conjugacy in $\mathrm{GL}_n(\mathbb C)$ is equivalent to conjugacy in
$\mathrm U_n(\mathbb C)$ [LT09](@cite), Theorem 1.33. The Shephard--Todd symbols are
classification labels for these conjugacy classes, rather than the definition of type.

For a unitary reflection group $G\subseteq\mathrm{GL}(V)$ there is an orthogonal
decomposition

```math
V=V^G\mathbin{\perp}V_1\mathbin{\perp}\cdots\mathbin{\perp}V_r
```

and a direct-product decomposition $G=G_1\times\cdots\times G_r$, where $G_i$ acts as an
irreducible reflection group on $V_i$ and trivially on the other summands. The sum
$V_1\mathbin{\perp}\cdots\mathbin{\perp}V_r$ is the **support** of $G$, and its dimension
is the **rank**. Consequently, rank is additive under direct products and the trivial type
has rank zero.

For an essential reducible reflection group, the conjugacy type is determined by the
unordered collection of the conjugacy types of its irreducible factors.
`ComplexReflectionGroupType` records this collection. Rank is not, in general, the
dimension of a nonessential ambient representation: the latter also contains the fixed
summand $V^G$. Adjoining a trivial summand changes the ambient dimension and hence the
ambient conjugacy problem; that extra dimension is not part of the essential type object
implemented here. The concrete models constructed here are essential, so
`rank(complex_reflection_group_type(W)) == degree(W)`. The irreducible types are
the infinite series and the exceptional Shephard--Todd types
$G_4,\ldots,G_{37}$ [ST54](@cite).

There are two catalogue conventions to keep in mind. The label `G(1,1,n)` used by this
component denotes the irreducible reflection representation
$S_n^{\mathrm{ref}}\subseteq\mathrm{GL}_{n-1}(\mathbb C)$, not the reducible permutation
representation of $S_n$ on $\mathbb C^n$. Also, the present essential catalogue identifies
the one-dimensional trivial representation with the empty support. A future API for full
ambient types must retain $\dim V^G$ and would distinguish those cases.

Primitivity is used here only for an irreducible, nontrivial reflection representation. A
rank-one type is primitive. The essential reflection representation
$S_n^{\mathrm{ref}}=G(1,1,n)$ is primitive for $n\geq5$; the case $n=4$ is imprimitive
because $S_4^{\mathrm{ref}}$ is equivalent to the monomial group $G(2,2,3)$.

### Hyperplane orbits and reflection classes

Let $\mathcal A$ be the set of reflecting hyperplanes of $G$. For $H\in\mathcal A$, the
pointwise stabilizer

```math
G_H=\{g\in G\mid g(v)=v\text{ for every }v\in H\}
```

is cyclic; write $e_H=|G_H|$. After choosing a generator $s_H$ compatibly along a
$G$-orbit $\mathcal O\subseteq\mathcal A$, the nonidentity powers
$s_H^j$, $1\leq j<e_H$, organize the reflections over that orbit. For fixed $j$, their
conjugates form one reflection conjugacy class, containing one reflection over each
hyperplane in $\mathcal O$; see [LT09](@cite), Proposition 1.20. Hence

```math
|\operatorname{Ref}(G)|
=\sum_{\mathcal O\in\mathcal A/G}|\mathcal O|(e_{\mathcal O}-1),
\qquad
|\operatorname{Ref}(G)/G|
=\sum_{\mathcal O\in\mathcal A/G}(e_{\mathcal O}-1).
```

The hyperplane orbits and the classes themselves are intrinsic. Their ordering and the
choice of $s_H$ are marking conventions. Keeping these layers separate is important, for
example, when attaching parameters to reflection classes in Cherednik-algebra
constructions.

## Types, reference markings, and realizations

A `ComplexReflectionGroupType` stores the normalized irreducible decomposition of an
essential conjugacy type, using Shephard--Todd labels for its irreducible factors. It has
structural equality and hashing, and `is_equivalent` tests equality of conjugacy types.
Classification overlaps are normalized;
in particular, $G(2,2,2)$ is stored as two rank-one factors.

```jldoctest
julia> T = complex_reflection_group_type([(2, 2, 2), 23])
Complex reflection group type G(1,1,2) x G(1,1,2) x G23

julia> rank(T)
5

julia> number_of_components(T)
3

julia> is_equivalent(T, complex_reflection_group_type([23, (1, 1, 2), (1, 1, 2)]))
true

julia> rank(complex_reflection_group_type([]))
0
```

The primitivity predicates require an irreducible nontrivial type:

```jldoctest
julia> is_primitive(complex_reflection_group_type(1, 1, 4))
false

julia> is_primitive(complex_reflection_group_type(1, 1, 5))
true
```

The type-level reference marking orders the normalized components and the hyperplane orbits
within each component. A [`ReflectionHyperplaneOrbitType`](@ref) records this component
index, a local orbit index, $e_H$, the orbit size, and a representative word in the CHEVIE
reference generators. The represented reflection fixes an orientation of the cyclic group
$G_H$, and a [`ReflectionClassType`](@ref) adds the power $j$. Component indices, local
indices, representative words, and power labels belong to the marking; they should not be
treated as canonical labels of an unmarked group.

Finally, `complex_reflection_group` constructs a marked matrix representative of the type.
The functions
`complex_reflection_group_type` and `complex_reflection_group_model` recover its type and
selected model. Changing the model changes concrete matrices and arithmetic data but not
their $\mathrm{GL}_n(\mathbb C)$-conjugacy type.

The built-in CHEVIE, Lehrer--Taylor, and Magma realizations also carry model-aware
identifications of their generator conventions with the full reference marking. This
includes taking a suitable power when a model generator has the right fixed hyperplane but
the inverse, or another primitive, nontrivial eigenvalue. Consequently, exponent $j$ labels
the same reference reflection class in every built-in model.

For a custom matrix realization that already has an assigned type,
[`set_reflection_hyperplane_orbit_marking!`](@ref) supplies one reflection for each
type-level orbit. The representatives are reference-oriented by default. If a supplied
representative is the $u$-th power of the reference reflection, the keyword
`class_exponents` records $u$ and normalizes it back to exponent one. This must be done
before computing concrete hyperplane orbits or reflection classes.

This orientation necessarily depends on the chosen presentation embedding of the
coefficient field. A Galois automorphism can permute the reference hyperplane-orbit labels
and can replace a distinguished eigenvalue $\zeta$ by $\zeta^a$, which changes the power
labels by $j\mapsto aj$. The Galois-conjugate group still has the same type
[LT09](@cite), Theorem 8.32, but the transformed model must transport both parts of its
marking rather than rediscover them from orbit sizes. This permutation-and-orientation datum
is useful for later Galois actions on Cherednik parameters.

## Matrix models, fields, and unitarity

As a first realization, construct the exceptional group $G_4$ using the Lehrer--Taylor
model [LT09](@cite). Its matrices are presented over $\mathbb Q(i,\omega)$, with
$\omega=\exp(2\pi i/3)$, represented here as a relative number-field tower.

```jldoctest crg_g4
julia> W = complex_reflection_group(4, :LT)
Matrix group of degree 2
  over relative number field of degree 2 over number field

julia> base_ring(W)
Relative number field with defining polynomial x^2 + x + 1
  over number field with defining polynomial x^2 + 1
    over rational field

julia> w = gens(W)[1];

julia> is_complex_reflection(w)
true

julia> is_unitary(w)
true

julia> ok, w_data = is_complex_reflection_with_data(w);

julia> ok
true

julia> (dim(root_line(w_data)), dim(hyperplane(w_data)), order(w_data))
(1, 1, 3)

julia> eigenvalue(w_data)^3 == 1
true
```

There are two different field notions here:

* The **field of definition** asks for a smallest field over which the conjugacy type has a
  matrix representative. It is type-level representation-theoretic data; see
  [LT09](@cite). This component does not currently compute it.
* `base_ring(W)` is the **presentation field** used for the entries of this particular
  realization. It can be larger than a field of definition and can be represented as a
  simple field or as a relative tower.

For a reducible type, the block-diagonal realization must place all components in one exact
coefficient field. The constructor first preserves an existing component presentation
field, including a relative tower, when all component fields have natural embeddings into
it. Otherwise it uses a common cyclotomic field when possible. Only as a final fallback
does it convert relative towers to isomorphic absolute simple fields and form an exact
compositum. This **tower flattening** is an implementation step, not a computation of the
field of definition. `complex_reflection_group_component_embeddings` returns the
embeddings used to transport the component matrices.

The Lehrer--Taylor models preserve the standard Hermitian form. The form supplied with a
model is available separately from the type:

```jldoctest crg_g4
julia> J = invariant_hermitian_form(W)
[1   0]
[0   1]

julia> is_unitary(W, J)
true
```

Here `is_unitary(W)` is shorthand for preservation of the standard form. More generally,
`is_unitary(W, J)` tests the form with Gram matrix `J`, using OSCAR's right-action
convention; it rejects a matrix `J` that is not Hermitian and nondegenerate. Over an exact
number field with no chosen archimedean embedding this test does not by itself certify that
`J` is positive definite. When positivity is known, it is the usual unitarity test.
[`invariant_hermitian_form`](@ref) returns a form supplied by the chosen model, or `nothing`
if the model supplies none. The latter does not mean that the finite group is not
unitarizable.

Different models serve different arithmetic purposes. For example, the Marin--Michel model
[MM10](@cite) implemented in CHEVIE [Mic15](@cite) gives rational fundamental invariants
for $G_4$:

```jldoctest
julia> W_chevie = complex_reflection_group(4, :CHEVIE)
Matrix group of degree 2
  over cyclotomic field of order 3

julia> fundamental_invariants(invariant_ring(W_chevie))
2-element Vector{MPolyDecRingElem{AbsSimpleNumFieldElem, AbstractAlgebra.Generic.MPoly{AbsSimpleNumFieldElem}}}:
 x[1]^4 - 8*x[1]*x[2]^3
 x[1]^6 + 20*x[1]^3*x[2]^3 - 8*x[2]^6

julia> is_unitary(W_chevie)
false

julia> invariant_hermitian_form(W_chevie) === nothing
true
```

Thus the CHEVIE matrices above do not preserve the standard form, and this model does not
supply another Gram matrix. This is a statement about the realization data, not the
existence of an invariant Hermitian form. The Magma model [BCP97](@cite) instead has
algebraic-integer entries in a cyclotomic field:

```jldoctest
julia> W_magma = complex_reflection_group(4, :Magma)
Matrix group of degree 2
  over cyclotomic field of order 3

julia> gens(W_magma)
2-element Vector{MatGroupElem{AbsSimpleNumFieldElem, AbstractAlgebra.Generic.MatSpaceElem{AbsSimpleNumFieldElem}}}:
 [z_3 0; -z_3-1 1]
 [1 z_3+1; 0 z_3]
```

## Reflecting-hyperplane orbits in the API

The theoretical hierarchy above is available without constructing matrices. For $G_6$ the
type catalogue has two hyperplane orbits. Their pairs $(e_H,|\mathcal O|)$ are $(2,6)$ and
$(3,4)$, so they produce three reflection classes:

```jldoctest
julia> T = complex_reflection_group_type(6);

julia> orbit_types = reflection_hyperplane_orbits(T);

julia> println([(pointwise_stabilizer_order(O), Int(number_of_hyperplanes(O))) for O in orbit_types])
[(2, 6), (3, 4)]

julia> representative_word(orbit_types[2])
(2,)

julia> class_types = reflection_classes(T);

julia> println([(local_orbit_index(C), reflection_exponent(C), Int(orbit_size(C))) for C in class_types])
[(1, 1, 6), (2, 1, 4), (2, 2, 4)]

julia> number_of_reflections(T)
14
```

For a marked matrix realization, the same functions return concrete hyperplane orbits and
concrete conjugacy classes. The catalogue labels are retained, while the hyperplanes and
reflections live in the selected model:

```jldoctest
julia> W = complex_reflection_group(6, :CHEVIE);

julia> orbits = reflection_hyperplane_orbits(W);

julia> println([(pointwise_stabilizer_order(O), orbit_size(O)) for O in orbits])
[(2, 6), (3, 4)]

julia> classes = reflection_classes(W);

julia> println([(local_orbit_index(C), reflection_exponent(C), orbit_size(C)) for C in classes])
[(1, 1, 6), (2, 1, 4), (2, 2, 4)]

julia> length(complex_reflections(W))
14
```

[`reflection_library`](@ref) gives the complementary hyperplane-first organization: first
by hyperplane orbit, then by individual hyperplane, and finally by the nonidentity powers
of its distinguished reflection. The innermost index $j$ is the same exponent $j$ used by
the corresponding [`ReflectionClassType`](@ref). No ordering of the individual hyperplanes
is part of the type-level marking.

## Symplectic doubling

If a group acts on $\mathfrak h$ by matrices $g$, its cotangent, or **symplectic,
doubling** acts on $\mathfrak h\oplus\mathfrak h^*$ by

```math
g^\star=
\begin{pmatrix}
g&0\\
0&g^{-\mathsf T}
\end{pmatrix}.
```

The function [`symplectic_doubling`](@ref) constructs this representation together with the
standard alternating form

```math
\Omega=
\begin{pmatrix}
0&I\\
-I&0
\end{pmatrix}.
```

It retains the source group, the row-space inclusions of $\mathfrak h$ and
$\mathfrak h^*$, and, when available, the source reflection-group type and model as
metadata. [`symplectic_reflection_group`](@ref) applies the construction to a known complex
reflection group and marks the result as a symplectic reflection group.

A complex reflection fixes a hyperplane, whereas its doubled transformation fixes a
codimension-two subspace and is a symplectic reflection. Consequently, the doubled group is
not assigned the complex reflection type of its source, and its geometry is not forced into
the cyclic pointwise-stabilizer and hyperplane-orbit schema above. The source metadata is
kept separately for constructions that need to recover $\mathfrak h$, $\mathfrak h^*$, or
the original complex reflection group.
