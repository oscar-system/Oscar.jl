# Comprehensive Gröbner systems

## Aims

This experimental module contains code for computing comprehensive Gröbner systems,
via `cgsdr` from Singular's `grobcov.lib`.

## Status

The module is currently under development.
A future aim is to add other related functionality,
such as computing Gröbner covers with the Montes-Wibmer algorithm
(`grobcov` in `grobcov.lib`).
