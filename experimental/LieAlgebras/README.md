# Bases for highest weight modules

## Aims

This project aims to provide functionality for Lie algebras and their representations.
It aims to provide the computational tools to work with the concepts defined in [Hum72](@cite) and [Bou02](@cite).


## Status

The different parts of this project are in widely varying states of development.
Parts of the code have already moved to `src/LieTheory`, parts are still in the experimental section but are already usable, and some parts are still in the very early stages of development and only contain very naive implementations.
